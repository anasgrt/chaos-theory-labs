# Lab numbering

The 27 retained labs are numbered 00 through 26 in their original order.
This map translates lab references in historical review reports. Theory section
numbers are unchanged. Old lab IDs are not aliases for current IDs.
The etcd-quorum lab (original ID 14, briefly ID 07) has been removed.
In the previous 28-lab catalog, IDs 08 through 27 move down by one; IDs
00 through 06 are unchanged.

Before using this catalog with an existing VM, save your results and clean up
its fixtures using the matching old checkout, or use a fresh VM. The new IDs
reuse old workspace and resource names; this change does not migrate a VM.
